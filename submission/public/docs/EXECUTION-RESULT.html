서버 대조에서 다섯 요청의 저장 응답과 B33로 표기된 감사 메타데이터가 일치했다. 이는 보고서의 로그 라벨이며 현재 소스의 실제 HTTP 메타 기록 노드는 B35다. 최신 n8n 원시 노드 실행을 열어 확인한 것처럼 설명하지 않는다.

n8n 실행 기록이 비어 있는 이유: 관측한 워크플로우 설정은 성공·실패·수동·진행 데이터 모두 Do not save였다. 실행 UI가 비어 있다고 요청이 실행되지 않은 것은 아니다. 별도로 일부 index/search SQLite row가 running/종료시각 없음으로 남는 현상은 원인 미확정이다. 사용자 응답·Jira·업무 저장·감사를 대조한 증거와 실행 저장 문제를 분리한다. 리허설 보고서, 서버 후속 확인

보존된 노드별 정상 예시는 11/06 실행 #305다. n8n 전체 13.138초, 응답 내부 11.584초였고 검색 1.889초·생성 2.167초·검증 1.361초·Jira 약 3.200초 등을 기록했다. 최신 리허설의 시간으로 옮기지 않는다. 상세 결과 원본, 원자료 13쪽 공개 텍스트, 원자료 14쪽 공개 텍스트. 원문 PDF와 화면 이미지는 공개에서 제외하고 텍스트 기록을 제공합니다. 이번에 실행한 캡처가 아닙니다.

5.2 5분 시연의 확정 순서

  1. n8n에서 실제 PR36 전체 흐름을 짧게 보여준다. 팀원 HTML의 모의 재생과 실제 실행을 구분한다.
  2. Discord에서 QR 정상 문의를 실행해 안내와 출처를 확인한다.
  3. 같은 반납 문의를 최초·추가 두 번으로 이어 보완 질문과 3회차 이관을 확인한다.
  4. 해외 이용 질문으로 근거 없음 이관을 보여준다. 가이드의 ‘검색 결과 없음 또는 외부 API 오류’ 중 실제 확인한 전자를 사용한다.
  5. Jira All 큐에서 티켓을 열어 같은 문의의 문맥, 담당자, 상태, 내부 메모를 보여준다. 직접 처리 범위를 설명한다.
  6. 저장/감사 대조 요약으로 응답뿐 아니라 처리 결과도 확인했음을 설명하고 9장 시험 결과로 돌아간다.

구체 입력·클릭 순서·발표 대사·예상 결과·대체 자료는 시연 실행 절차에 있다. 리허설의 기능 확인은 완료했으나 연속 5분·전체 20분 시간은 편성값이다. 실제 화면 최대화·스크롤·발표자 창의 현장 검수는 자동 브라우저의 로컬 파일 접근 제한으로 미확인이다.

Jira All 확인: 11/09 사용자가 전체 조회로 변경하고 이름을 All로 바꿨다. 이후 읽기 전용 UI 확인에서 필터 project = JBYS ORDER BY "Time to resolution" ASC와 Done·In Progress·To Do 행을 함께 관측했다. 이전 ‘미해결 큐에 완료 티켓이 안 보임’ 현상을 현재 상태로 설명하지 않는다. 우리 작업에서 큐 조건이나 티켓은 변경하지 않았다.

6. 제출 전 체크리스트

원 가이드 15개 항목을 유지한다. 체크는 아래 적은 확인 범위에만 적용하며 빈칸은 현재의 한계를 뜻한다.

노코드 워크플로우 설계서

  • Trigger → 처리 → 출력 흐름이 실제 구현과 일치한다. — 로컬 JSON과 대표 VM 관측 기준. VM 전체 export 동일성은 별도 미확인.
  • 병렬·분기·루프 구조의 사용 목적이 명확하다.
  • 외부 연동별 인증 및 오류 처리를 기록했다.
  • 노드 간 페이로드의 필수·선택 필드와 변환 로직을 작성했다. — 주요 경계 표와 원본 상세·실제 연결 부록 포함.

RAG 아키텍처 설계서

  • 청킹 단위·오버랩·길이 분포와 선정 근거를 작성했다.
  • 임베딩 모델 선정 이유와 실제 벡터 차원을 기록했다.
  • 거리 계산 방식과 인덱스·메타데이터 구조를 작성했다.
  • 백업·복구 및 확장 방안을 작성했다. — 구현·관측·후속안을 구분.

워크플로우 실행 결과서

  • 주요 시나리오별 실행 테스트 로그가 있다.
  • 예외 상황의 실제 처리 결과가 있다. — 모든 예외를 전수 실행했다는 뜻은 아님.
  • 기대 결과와 실제 결과를 구분했다.
  • 실패 사례와 재시험 결과를 기록했다.

공통

  • 세 설계서·결과서의 내용이 실제 구현과 일치한다. — 소스/관측 범위의 일관성은 점검했으나 현 VM 모든 JSON·Credential·이미지의 전수 동일성은 확인하지 못했다.
  • 예시 수치를 팀의 실제 측정값으로 교체했다. — 미측정은 미측정, 계획값은 계획으로 표시.
  • 인증정보와 개인정보가 문서·로그·저장소에 노출되지 않았다. — 제출·공개 후보 대체 검사는 별도 기록. 서버 모든 과거 원시 실행·Git 전체 이력 무노출을 보증하지 않는다.

체크리스트의 미확인 항목을 지우지 않고 제출한다. 최종 로컬 검사 결과·패키지·Git 기준은 마감 검증 기록과 제출 안내를 따른다. 실제 강사 제출·발표 수행·피드백은 이 문서 작성과 별도다.
