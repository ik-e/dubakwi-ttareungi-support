## 반납 방법

서울시설공단 FAQ에 따르면 대여한 곳과 관계없이 가까운 따릉이 대여소에서 반납할 수 있다. 자전거를 거치대에 거치하고 뒷바퀴 부분의 잠금장치를 당겨 잠근다.

## 반납 완료 확인

반납 후 따릉이 앱 알림, 알림톡 또는 문자 등으로 반납 완료를 확인해야 한다. FAQ는 반납 알림이 오지 않으면 정상 반납되지 않았을 수 있으므로 콜센터에 문의하도록 안내한다.

- 출처: [서울시설공단, 자전거 반납 방법](https://www.sisul.or.kr/open_content/globalcenter/bbs/bbsMsgDetail.do?bcd=faq&msg_seq=485&pgno=7)
- 자료 구분: 공식 공개 안내. 확인일: 2026-11-03.

## 미반납 알림이 온 경우

반납했다고 생각했는데 미반납 알림이 왔다면 개별 이용 기록과 실제 상황 확인이 필요하다. FAQ는 잠금이나 통신 등의 가능성을 다루지만, 문의 내용만으로 원인이나 반납 완료 여부를 확정할 수 없다.

- 출처: [서울시설공단, 반납 후 미반납 알림](https://www.sisul.or.kr/open_content/worldcup/bbs/bbsMsgDetail.do?bcd=faq&msg_seq=486&pgno=7)
- 자료 구분: 공식 공개 안내. 확인일: 2026-11-03.

## 두바퀴의 가상 반납 문의 처리

교육용 두바퀴에서는 사용자가 제공한 반납 장소·시각, 잠금 여부, 완료 알림과 앱 표시 내용을 정리한다. 문의 처리에 필요한 정보가 부족하면 보완 질문을 준비한다. 반납 상태가 계속 불분명하거나 개별 기록 확인이 필요하면 가상 담당자에게 이관한다. 안내나 티켓 생성만으로 반납 완료를 확정하지 않는다.

- 자료 구분: 팀의 교육용 가상 정책. 출처: [팀 주제 설계](../project/TOPIC.md). 실제 따릉이 운영 절차가 아니다. 구현·시험: 미완료.

## 앱 챗봇 직접반납 안내: 사용자가 확인한 내용

사용자는 따릉이 앱 챗봇에서 자전거 옆에서 앱의 직접반납 또는 직접반납요청을 시도하고, 알림이 오지 않으면 상담 채널에 문의한다는 안내를 확인해 제공했다. 서울자전거 가족권 매뉴얼의 예시 화면에도 직접반납 요청 버튼이 표시되어 있다. 앱 화면을 독립적으로 확인하지 못했으며 사용자의 확인 날짜·앱 버전은 전달되지 않았다. 현재 버튼 위치와 사용 조건도 다시 확인할 수 있다.

사용자가 앱 챗봇에서 복사한 안내에는 대여소 밖 임시잠금이 반납이 아니라는 설명과 추가요금 상한도 포함되어 있다. 상한 금액 및 현재 적용 조건은 별도로 확인할 수 있다. 요금에 관한 검토 상황은 [요금·환불 안내](fees-refund-guide.md)를 참고한다.

- 자료 구분: 사용자가 따릉이 앱 챗봇에서 직접 확인해 제공한 안내 요약 및 공식 과거 화면 참고. 전달받은 날짜: 2026-11-03. 앱 화면의 독립 확인·당시 버전: 미확인.
