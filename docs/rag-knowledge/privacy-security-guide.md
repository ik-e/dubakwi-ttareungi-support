# 계정 및 개인정보 안내

> 상태: 검토 전 초안. 실제 기관의 보안 사고 대응 지침은 확인하지 않았다. 두바퀴 가상 대응·이관 기준은 사용자 확인 전 미작성이다. 승인 전 검색 색인에 넣지 않는다.

## 아이디 또는 비밀번호 찾기

서울시설공단 FAQ는 앱과 홈페이지의 계정 찾기 및 본인 인증을 통한 비밀번호 관련 절차를 안내한다. 실제 앱의 현재 메뉴 이름과 절차는 다시 확인해야 한다.

- 출처: [서울시설공단, 아이디·비밀번호 찾기 FAQ](https://www.sisul.or.kr/open_content/worldcup/bbs/bbsMsgDetail.do?bcd=faq&msg_seq=495&pgno=6)
- 자료 구분: 공식 공개 안내. 확인일: 2026-11-03. 원문 갱신일: 미확인.

## 개인정보 관련 문의

서울시설공단 개인정보 처리방침에는 개인정보 처리와 정보주체의 권리·문의에 관한 안내가 있다. 공단 전체에 관한 방침이므로 특정 사고의 처리 완료를 보장하는 문서로 해석하지 않는다.

- 출처: [서울시설공단 개인정보 처리방침](https://www.sisul.or.kr/open_content/main/guidance/pim.jsp)
- 자료 구분: 공식 공개 안내. 확인일: 2026-11-03.

## 계정 노출 또는 침해가 의심되는 경우

따릉이 내부 사고 대응 매뉴얼과 프로젝트의 구체적인 가상 이관 기준은 확인되지 않았다. 계정의 침해 여부나 조치 완료를 이 문서만으로 확정할 수 없다.

- 자료 구분: 확인되지 않은 항목. 가상 정책: 사용자 확인 대기.
