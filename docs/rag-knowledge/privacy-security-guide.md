# 계정 및 개인정보 안내

> 상태: 검토 전 초안. 실제 기관의 보안 사고 대응 지침은 확인하지 않았다. 아래 프로젝트 정책은 교육용 가상 설계이며 아직 구현·검증되지 않았다. 승인 전 검색 색인에 넣지 않는다.

## 앱 챗봇 회원가입 안내: 사용자가 확인한 내용

사용자가 따릉이 앱 챗봇에서 복사한 안내에 따르면 회원가입은 만 14세 이상과 법정대리인 동의가 필요한 만 13세로 구분된다. 가입 및 비회원 이용 시 본인 명의 휴대전화 인증을 안내하며, 만 13세는 보호자 본인인증을 안내한다. 회원가입은 앱의 회원 → 회원가입 → 일반가입에서 연령을 선택하는 방식으로 설명한다.

가입 실패 원인으로 입력 정보 불일치, 이미 가입된 휴대전화 번호가 제시되며 법인 전화는 통신사 실사용자 등록 안내가 있다. 인증번호 미수신 시 통신사·번호 선택과 1599 번호 차단 여부 확인을 안내한다. 타인의 계정·이용권 사용 시 사고 보험 적용이 제한될 수 있다는 안내도 있다.

- 자료 구분: 사용자가 따릉이 앱 챗봇에서 확인해 제공한 안내의 요약. 전달일: 2026-11-03. 앱 버전·독립적인 화면 확인: 미확인.

## 앱 챗봇 로그인 안내: 사용자가 확인한 내용

사용자가 제공한 챗봇 안내는 회원·SNS·간편 로그인을 설명한다. SNS 로그인은 안드로이드에서 회원정보 변경의 연동 설정을 통해 이용한다고 안내하며, 아이폰에서는 SNS 로그인이 불가하다고 설명한다. 간편 로그인은 자동 로그인과 간편비밀번호 설정, 앱 재설치 후 재등록에 관한 안내가 있다. 기종·앱 버전별 현재 지원 범위는 별도 확인한다.

- 자료 구분: 사용자가 따릉이 앱 챗봇에서 확인해 제공한 안내의 요약. 전달일: 2026-11-03. 앱 버전·독립적인 화면 확인: 미확인.

## 앱 챗봇 계정 찾기와 회원정보 변경

사용자가 제공한 안내에는 앱 로그인 화면의 아이디 찾기와 비밀번호 찾기, 홈페이지의 아이디·비밀번호 찾기 경로가 있다. 아이디 일부는 가려서 표시되며 추가 확인은 본인 확인 후 고객센터 또는 채팅 상담으로 문의하도록 안내한다. 임시 비밀번호 로그인 후 변경과 앱 내정보의 회원정보 변경 경로도 안내한다.

- 자료 구분: 사용자가 따릉이 앱 챗봇에서 확인해 제공한 안내의 요약. 전달일: 2026-11-03. 실제 화면·버전 독립 확인: 미확인.

## 앱 챗봇 회원탈퇴 안내

사용자가 제공한 안내는 앱 로그인 후 내정보 → 회원정보 변경 → 회원탈퇴 경로를 설명한다. 탈퇴한 아이디를 다시 사용할 수 없고, 사용 중인 이용권이 있으면 앱에서 탈퇴할 수 없어 고객센터에 문의하도록 안내한다. 현재 이용권 상태별 적용 조건과 앱 화면은 독립적으로 확인하지 않았다.

- 자료 구분: 사용자가 따릉이 앱 챗봇에서 확인해 제공한 안내의 요약. 전달일: 2026-11-03. 앱 버전·독립적인 화면 확인: 미확인.

## 두바퀴의 가상 보안 문의 이관

두바퀴 교육용 시연에서는 계정 정보 노출이나 침해가 의심되는 문의를 긴급으로 분류해 가상 담당자 티켓과 알림으로 이관하도록 설계한다. 확인된 공개 안내만 초동 안내의 근거로 사용한다. 비밀번호·인증번호 등 비밀을 문의나 로그에 남기도록 요구하지 않는다.
