# 따릉이 상담 및 문의 후속 안내

> 상태: 검토 전 초안. 실제 신고·상담 티켓의 처리 단계와 조회 절차는 확인하지 못했다. 아래 프로젝트 정책은 교육용 가상 설계이며 아직 구현·검증되지 않았다. 승인 전 검색 색인에 넣지 않는다.

## 따릉이 채팅 상담

서울시의 2025년 안내는 따릉이 앱에서 채팅 상담을 통해 이용 안내, 계정, 결제·이용권, 대여·반납, 환불, 사고·보험, 고장 신고, 분실물 등 문의 유형을 제공한다고 설명한다.

- 출처: [서울시, 따릉이 앱 챗봇 상담 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223)
- 자료 구분: 공식 공개 안내. 안내 게시일: 2025-12-29. 확인일: 2026-11-03.

## 상담사 연결

위 서울시 안내에는 복잡한 문의에 상담사 직접 연결 기능이 소개되어 있다. 현재 앱 화면과 상담 가능 시간은 별도로 확인해야 한다.

- 출처: [서울시, 따릉이 앱 챗봇 상담 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223)
- 자료 구분: 공식 공개 안내. 안내 게시일: 2025-12-29. 확인일: 2026-11-03.

## 사고와 보험 관련 문의

사용자가 제공한 앱 챗봇은 사고 발생 및 보험 문의 시 상담원 연결이나 따릉이 고객센터를 통한 확인을 안내한다. 제공된 보험 화면에는 종합보험과 영조물 배상공제의 서로 다른 접수 안내가 있으나, 실제 적용 중인 보험사·연락처·절차는 확인이 필요하다. 두바퀴의 가상 티켓 생성은 실제 사고나 보험 청구 접수가 아니다.

- 자료 구분: 사용자가 앱 챗봇에서 확인한 안내와 제공 화면의 요약. 전달일: 2026-11-04. 현행 접수처·보험기간: 미확인.

## 분실물·습득물 문의

사용자가 제공한 챗봇은 분실물 문의 시 반납한 대여소와 자전거 번호를 확인하도록 안내한다. 현재 전달된 내용에는 구체적인 신고 버튼, 접수 경로 및 습득물 처리 방법이 포함되지 않아 확인이 필요하다. 자전거 자체의 분실·도난과 자전거에 두고 내린 물건의 분실은 구분한다.

- 자료 구분: 사용자 제공 앱 챗봇 안내. 전달일: 2026-11-04. 세부 신고 절차: 확인 필요.

## 문의 처리 상태 조회

공식 자료에서 개별 신고·상담 티켓의 상세 처리 상태를 조회하는 절차는 확인하지 못했다. 대여·반납 이력 조회를 신고 처리 상태 조회와 동일하게 취급하지 않는다.

- 자료 구분: 확인되지 않은 공식 정보. 확인일: 2026-11-03.

## 두바퀴의 가상 문의 조회 정책

교육용 두바퀴는 서버에서 확인한 가상 이용자에게 본인이 접수한 가상 문의의 상태를 안내하도록 설계한다. 질문에 적힌 이름만으로 소유자를 결정하지 않는다. 타인의 문의 내용·상태·연락처는 보여주지 않는다. 가상 사용자 매핑은 실제 본인 인증이 아니다.

이번 조회 문의로 새로 생성하는 가상 티켓과 사용자가 조회하려는 기존 티켓은 서로 다른 건이다. 실제 조회된 값만 안내하고, 기록이 상충하거나 추가 판단이 필요하면 담당자에게 넘기도록 설계한다. 조회 서비스를 사용할 수 없으면 상태를 추측하지 않는다.

- 자료 구분: 팀의 교육용 가상 정책. 출처: [팀 주제 설계](../project/TOPIC.md). 실제 따릉이 서비스 정책이 아니다. 구현·시험: 미완료.

## 두바퀴의 가상 보완 질문과 이관

문의에 필요한 정보가 부족하면 최대 두 차례 보완 질문을 하고, 세 번째 시도에도 판단이 어려우면 담당자에게 이관하도록 팀이 설계했다. 신체 위험이나 계정 침해가 의심되는 긴급 문의는 추가 정보가 부족해도 긴급 이관을 우선한다. 안내 완료는 안내를 제공한 상태이며 실제 문제가 해결됐다는 뜻이 아니다. 담당자 알림이나 티켓 생성은 실제 담당자의 인수 또는 문제 해결을 뜻하지 않는다. 생성·전달 결과가 확인되지 않으면 성공으로 표시하지 않는다.

- 자료 구분: 팀의 교육용 가상 정책. 출처: [팀 주제 설계](../project/TOPIC.md). 실제 기관의 상담 절차가 아니다. 구현·시험: 미완료.

## 상담 가능 시간에 관한 공개 안내

서울시 2025-12-29 안내에는 상담사 채팅이 평일 09:00~18:00, 점심시간 제외로 기재되어 있다. 점심시간의 세부 시간과 현재 운영 여부는 해당 안내만으로 확인하지 못했다.

- 출처: [서울시 따릉이 앱 챗봇 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223). 확인일: 2026-11-04.

## 두바퀴 교육용 가상 분실물 문의 처리

**가상 정책 — 따릉이의 실제 신고·습득물 처리 절차가 아니다.** 시연에서는 시민이 분실한 물건의 종류, 마지막 이용 대여소와 대략적인 시각, 자전거 번호를 알고 있는지 확인한 뒤 가상의 담당자에게 문의를 전달한다. 정확한 접수 경로나 보관 장소는 확인되지 않았으므로 추측하지 않는다. 가상 티켓은 실제 신고 접수를 의미하지 않는다.

- 자료 구분: 사용자 요청에 따른 교육용 가상 예시. 구현·검증: 미완료.
