# 따릉이 상담 및 문의 후속 안내

> 상태: 검토 전 초안. 실제 신고·상담 티켓의 처리 단계와 조회 절차는 확인하지 못했다. 프로젝트용 가상 조회·이관 정책은 사용자 확인 전 미작성이다. 승인 전 검색 색인에 넣지 않는다.

## 따릉이 채팅 상담

서울시의 2025년 안내는 따릉이 앱에서 채팅 상담을 통해 이용 안내, 계정, 결제·이용권, 대여·반납, 환불, 사고·보험, 고장 신고, 분실물 등 문의 유형을 제공한다고 설명한다.

- 출처: [서울시, 따릉이 앱 챗봇 상담 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223)
- 자료 구분: 공식 공개 안내. 안내 게시일: 2025-12-29. 확인일: 2026-11-03.

## 상담사 연결

위 서울시 안내에는 복잡한 문의에 상담사 직접 연결 기능이 소개되어 있다. 현재 앱 화면과 상담 가능 시간은 별도로 확인해야 한다.

- 출처: [서울시, 따릉이 앱 챗봇 상담 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223)
- 자료 구분: 공식 공개 안내. 안내 게시일: 2025-12-29. 확인일: 2026-11-03.

## 문의 처리 상태 조회

공식 자료에서 개별 신고·상담 티켓의 상세 처리 상태를 조회하는 절차는 확인하지 못했다. 대여·반납 이력 조회를 신고 처리 상태 조회와 동일하게 취급하지 않는다. 두바퀴 교육용 조회 정책은 사용자 확인 전 미작성이다.

- 자료 구분: 확인되지 않은 항목. 가상 정책: 사용자 확인 대기.
