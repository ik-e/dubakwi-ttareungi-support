## 해석 주의

- 3번과 5번의 이용권 유효기간은 각각 **3년과 1년**으로 달라 보인다. 촬영 시점과 현행 정책이 확인되지 않아 어느 쪽을 현재 기준으로 확정하지 않는다.
- 보험 자료에는 **2025년** 계약 기준이 표시되어 있다. 현재 보험사, 보장 한도, 접수 절차와 적용 기간은 미확인이다.
- 자료는 원문 기록으로 보존하며, 현행 정책이나 승인된 RAG 정답으로 자동 취급하지 않는다.
