# 따릉이 챗봇 조사 요약과 출처

- 정리일: 2026-11-05 KST
- 범위: 팀이 직접 작성한 조사 요약과 공개 출처 링크. 원문·사진은 내부 보관한다.
- 공개 범위 결정: 사용자의 원문 내부 보관·출처/자체 요약 공개 지시에 따라 R01이 취합했다. 실제 기관의 지식 승인이나 RAG 색인 승인이 아니다.

## 조사에서 프로젝트에 반영한 내용

| 주제 | 두바퀴 설계에 반영한 점 |
| --- | --- |
| 이용 방법·계정 | 일반 안내와 본인 확인이 필요한 개별 문의를 구분한다. 이용자의 역할 자기 선언을 권한으로 사용하지 않는다. |
| 대여·반납 | 자전거·장소·시각·앱 표시 등 필요한 사실을 보완하고, 안내와 실제 조치의 완료를 구분한다. |
| 결제·환불 | 일반 신청 방법 안내와 개별 금액·승인 판단을 분리한다. 후자는 담당자 검토 대상으로 둔다. |
| 사고·보험 | 일반 안내로 종결할 수 없는 위험·사고 문의는 사람의 검토에 연결한다. 오래된 보험 화면을 현재 보장 조건으로 단정하지 않는다. |
| 고장·분실 | 신고 대상과 필요한 정보를 정리해 전달하며, 실제 현장 처리·반납·환불을 자동 수행했다고 표시하지 않는다. |
| 후속 문의 | 문서 검색 권한과 개별 티켓 소유권을 별도로 검사한다. |

위 표는 조사 자료의 원문 전재가 아니라 프로젝트가 채택한 처리 방식의 요약이다. 실제 요금·환불·보험·이용 자격의 현행 조건은 공식 안내에서 별도 확인해야 한다.

## 자료 간 차이와 확인 한계

수집 화면에는 미사용 이용권 유효기간이1년과3년으로 다르게 표시돼 있다. 보험 자료에는2025년 기준이 보인다. 정확한 수집일·앱 버전·일부 원문 URL을 확인하지 못했으므로 어느 화면을 현재 정책으로 확정하지 않는다. 원문을 임의로 수정하거나 이 내용을 승인된 검색 정답으로 자동 등록하지 않는다.

[자료별 출처·확인 상태](source-index.md)에서 제공된 공식 안내 링크와 미확인 항목을 확인할 수 있다. 팀 내부 원문은 Git에서 제외한 별도 자료로 유지한다.
