# 로컬 n8n RAG 남은 개발 계획

작성: 2026-11-04 · 담당: R03. 상태: 계획. 실제 색인·검색·권한 적용 및 VM 시험은 완료되지 않았다. 작업 브랜치 `r03/p10-local-n8n-rag`, [이슈 #9](https://github.com/ik-e/dubakwi-ttareungi-support/issues/9), [PR #10](https://github.com/ik-e/dubakwi-ttareungi-support/pull/10).

## 현재까지 확인

로컬 n8n 1.120.4가 동작하고 OpenAI Credential로 `text-embedding-3-large`의 짧은 임베딩 API 호출이 성공했다. 임시 연결 시험은 실제 지식 색인·검색이나 권한 검증이 아니다. 지식 목록은 승인 대기이며 실험은 교육용 자료에 한정한다. R02 내부 검색 계약 및 R04 모의 역할·접근값은 확인했으나 실제 연결은 미완료다.

## 개발 순서

1. **문서와 청크 준비**: manifest의 문서 경로·권한·해시와 실제/가상 구분, 출처·확인일을 확인한다. 공식 내용과 가상 설정이 혼합된 부분을 분리하고 승인 대기 자료는 명시적인 로컬 교육용 시험에서만 사용한다. 원문 HTML은 색인하지 않는다. 완료 기준: 8개 문서와 청크의 근거·권한·유형을 검사하고 오류가 있는 입력은 색인하지 않는다.
2. **색인 워크플로우 P10**: `workflows/dubakwi-index.json`을 로컬 n8n에서 만들고 `text-embedding-3-large`와 Simple Vector Store에 연결한다. 시민용 public과 담당자용 restricted 키를 분리한다. n8n 데이터 로더가 반복 항목을 처리할 때 내용·메타데이터가 섞이지 않는지 검증한다. 완료 기준: 8개 문서의 교육용 청크 삽입 수와 문서별 검색 확인, 실패 시 성공으로 표시하지 않음. 비용·모델·설정·실측 기록.
3. **검색 워크플로우 P16**: `workflows/dubakwi-search.json`에서 POST `/webhook/dubakwi-search`, 내부 `X-Internal-Key` 인증, 서버가 확인한 access_levels를 사용한다. 시민 public, 담당자 public+restricted를 검색 전 분리하고, 미확인 권한은 거절한다. request_id와 `ok`/`empty`/`skipped`/`error`, 필수 Evidence 필드 및 `[실제 안내]`/`[가상 설정]`을 유지한다. 완료 기준: 테스트 요청으로 각 상태·필수 필드 확인, 임의 권한 선택 불가.
4. **검색·권한 시험**: 시민과 담당자의 공개·제한 문서 검색, 두 제한 canary 및 문서 ID·본문·sources 비노출을 확인한다. WF01·WF03·WF05·WF10·WF12와 TC04·TC09·TC10 등은 메인·조회 기능 연결 범위에 맞춰 시험한다. WF03은 검색 결과 없음과 답변 근거 부족을 별도 판정한다. 사용자 역할 fixture만으로 실제 인증이 완료된 것으로 표시하지 않는다. 완료 기준: 입력·예상·실제·버전과 통과/실패 기록, 제한 노출 0.
5. **재시작 및 복구**: Simple Vector Store가 비영속임을 확인하고 n8n 재시작 시 준비 안 됨을 오류로 반환하도록 검증한다. 재색인 후 검색 및 권한을 재시험한다. 완료 기준: 재시작 전후와 재색인 시간·결과 기록, 실패한 후보 색인을 활성화하지 않음.
6. **팀 연결과 인계**: R02 메인 흐름에서 검색만 실제로 연결하고 상태·이관 mock을 실제 연동과 구분한다. R04의 서버 사용자 ID·역할 매핑 및 인증과 연계하고 R05가 사례를 실행한다. 실제/가상 표시는 R02의 최종 시민 답변에서도 확인한다. 로컬 결과 후 R01에 VM 버전·노드·Credential·재색인 방법을 전달하고 VM 시험은 별도 기록한다.

## 완료 기준과 이슈·PR

- 이슈 #9 및 PR #10은 실제 로컬 색인·검색 구현, API 호출, 권한 및 빈 결과/오류·재시작 시험의 결과와 남은 제한을 기록한 뒤 완료 처리한다. 완료 전에는 열어 둔다.
- 이슈 #5는 해당 전체 검색·권한 범위가 별도로 완료되었는지 확인 후 닫는다. 이슈 #1은 지식 검토·승인 등 해당 완료 기준이 충족됐는지 확인 후 닫는다.
- PR은 리뷰/병합이 필요한 팀 작업이므로 구현 완료만으로 병합된 것으로 표시하지 않는다. 사용자가 요청한 완료 즉시 정리 기준을 따르며 병합 또는 닫힘 상태를 정확하게 구분한다.

## 이번 계획의 제외·의존 사항

팀 VM 연결, 실제 기관 자료·실제 사용자 인증, Jira/상태 저장 등은 각각 담당 연결 전까지 완료로 판단하지 않는다. Simple Vector Store의 메모리 키는 인스턴스 사용자에게 공유될 수 있어 실제 민감 정보를 넣지 않는다. 개인 OpenAI 키는 n8n Credential에만 보관하며 코드·로그·PR에 복사하지 않는다.
