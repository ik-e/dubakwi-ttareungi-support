# 따릉이 고장 신고 안내

> 상태: 검토 전 초안. 2026-11-03 공식 FAQ 확인. 기관 내부 정비 절차는 확인하지 않았다. 승인 전 검색 색인에 넣지 않는다.

## 이용 중 자전거가 고장 난 경우

서울시설공단 FAQ는 고장 난 자전거를 가까운 대여소에 반납한 후 따릉이 앱 또는 콜센터로 고장을 신고하도록 안내한다. 이용자가 안전하게 이동할 수 있는지는 개별 상황에 따라 확인해야 한다.

- 출처: [서울시설공단, 운행 중 고장 FAQ](https://www.sisul.or.kr/open_content/traffic/bbs/bbsMsgList.do?bcd=faq&pgno=5)

## 파손이 심하거나 이동하기 어려운 경우

FAQ는 파손이 심하거나 이동하기 어려우면 임시잠금 후 콜센터에 신고하도록 안내한다. 해당 문구를 모든 상황에서 이동하라는 안내로 바꾸지 않는다.

## 두바퀴의 가상 고장 문의 이관

교육용 두바퀴에서는 신고 방법을 묻는 일반 문의와 실제 고장 신고·현장 조치를 요청하는 문의를 구분하도록 설계한다. 후자는 필요한 정보를 확인해 가상 담당자에게 이관한다. 신체 위험이나 사고가 의심되면 긴급 이관을 우선한다. 티켓 작성만으로 실제 신고 접수나 정비가 완료된 것은 아니다.

- 자료 구분: 팀의 교육용 가상 정책. 출처: [팀 주제 설계](../project/TOPIC.md). 실제 기관의 정비 절차가 아니다. 구현·시험: 미완료.

공식 FAQ에 나온 신고 경로는 따릉이 앱과 콜센터다. 이 문서는 고장 원인이나 실제 신고 접수·정비 완료 여부를 확정하지 않는다.

## 대여 전 안전 점검

앱 챗봇에서 연결된 자전거 이용 가이드와 안전수칙은 대여 전 타이어 공기압·브레이크·체인과 안장·페달을 점검하고, 안전모 등 보호장구를 착용하도록 안내한다. 횡단보도에서는 내려서 자전거를 끌고 가도록 설명한다. 문제가 있는 자전거는 안전하게 이용할 수 있는지 확인하고 고장을 신고한다.

- 출처: [자전거 이용 가이드](https://docs.channel.io/bikeseoul/ko/articles/%EC%9E%90%EC%A0%84%EA%B1%B0-%EC%9D%B4%EC%9A%A9-%EA%B0%80%EC%9D%B4%EB%93%9C-adeaf778), [안전수칙](https://docs.channel.io/bikeseoul/ko/articles/%EC%95%88%EC%A0%84%EC%88%98%EC%B9%99-a77d5149).
- 자료 구분: 사용자가 앱 챗봇에서 확인한 링크의 안내. 페이지 본문 확인일: 2026-11-03. 페이지 갱신일: 미확인.

## 자전거 번호와 고장 신고 메뉴

자전거 이용 가이드는 자전거 오른쪽 체인커버 위의 번호를 고장·방치 신고에 활용하도록 설명한다. 단말기 이상 등 고장 신고는 앱의 메뉴 → 고객센터 → 고장신고 경로를 안내한다. 실제 화면은 앱 버전에 따라 확인이 필요하다.

- 출처: [따릉이 앱 챗봇 자전거 이용 가이드](https://docs.channel.io/bikeseoul/ko/articles/%EC%9E%90%EC%A0%84%EA%B1%B0-%EC%9D%B4%EC%9A%A9-%EA%B0%80%EC%9D%B4%EB%93%9C-adeaf778).

## 앱 챗봇에서 사용자가 확인한 안전수칙 링크
