# P08 자료 검토 및 검색 평가 초안

작성 2026-11-04. R03 초안, R04·R05 검토 전. 평가 질문은 기대 결과이며 검색을 실행하거나 성능을 측정한 결과가 아니다. 문서의 가상 설정은 실제 따릉이 정책이 아니다.

## 충돌과 미확인 사항의 처리

| 항목 | 자료와 판단 근거 | 두바퀴 교육용 가상 설정과 한계 |
| --- | --- | --- |
| 상품권 결제 | 기존 챗봇은 지역 상품권 결제 불가라고 하나 2026-09-15 공단 공지는 일부 광역 상품권 허용 | **가상 충돌 처리:** 구체적 조건이 있는 최신 공지를 시연 기준으로 채택. 모든 상품권 결제 가능은 아님. |
| 가족권 연령 | 일반 가입 안내와 만 13세 미만 가족권 예외를 혼동할 수 있음 | **가상 충돌 처리:** 일반 가입과 보호자 감독 가족권을 구분. 실제 자격·보험 조건은 미확정. |
| 미사용권 1년/3년 | 사용자 제공 화면이 상충하며 따릉이 공개 약관 제13조는 1년을 제시 | **가상:** 미사용 회원권 1년. 실제 최신 약관 적용일과 권종별 예외는 확정하지 않음. |
| 비회원 24시간 | 제공 챗봇은 24시간 미사용 자동취소를 안내하나 약관 일반 기준과의 관계 미확인 | **가상:** 개별 자동취소 결과를 가정하지 않고 가상 담당자 확인으로 연결. |
| 보험 | 제공 화면에 2025 계약 체결일과 보장 항목이 있으나 현행 기간·조건 미확인 | **가상:** 긴급 문의를 가상 이관. 실제 보장액·접수 성공을 확정하지 않음. |
| 분실물·습득물 | 물건 종류와 대여소·자전거 번호 확인 외 세부 접수·보관 경로 미확인 | **가상:** 관련 사항을 확인하여 가상 문의 생성. 실제 접수 또는 보관 위치 주장 금지. |
| 방치신고 | 경로는 제공받았지만 첨부 사진은 고장신고 화면 | **가상:** 신고 문의를 가상 이관하며 화면의 세부 입력이나 실제 회수를 가정하지 않음. |
| 상담시간 | 2025 서울시 안내는 평일 09~18시, 점심 제외; 현재 시간과 점심시간 미확인 | **가상:** 시연 상담시간을 평일 09~18시로 설정하고 점심시간은 판단하지 않음. |
| 재배치 마일리지 | 원문은 2025 임시종료, 시간 표현은 불명확 | **가상:** 시연에서 미운영. 현행 제도 여부나 시간은 알 수 없음. |
| 가족권 조건 | 대여 순서는 제공되었으나 현재 가족관계·연령·보험 예외는 미확인 | **가상:** 일반권 먼저, 가족권 나중 대여를 시연하되 실제 자격·보험은 판단하지 않음. |
| 계정·티켓 상태 | 내부 보안 지침과 실제 문의 상태 조회는 확인되지 않음 | **가상:** 침해 의심 긴급 이관과 본인 모의 티켓 상태 조회만 시연. 실제 조치·접수 아님. |

확인한 근거: [따릉이 약관](https://www.bikeseoul.com/upload/TermsofUse/TermsofUse%2811.3.~%29.pdf), [서울시 상담 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223), 사용자 제공 원문·화면. 약관 적용 시점 및 현행성은 별도 확인 필요.

## 팀 인계와 검토 대기

- R02: 문서의 제목·절과 Evidence 계약의 매핑, 검색 오류와 근거 없음 분기 확인.
- R04: 서버 권한의 실제 값과 공개/제한 partition 및 가상 이관 정책 검토.
- R05: 위 질문의 기대 근거와 권한·가상 표기·오류 판정 검토.
- 모든 manifest 항목은 `pending_review`, `index_enabled=false`. 승인 및 실제 검색·권한 시험은 수행되지 않았다.
