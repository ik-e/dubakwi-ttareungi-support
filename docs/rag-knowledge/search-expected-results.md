# RAG 검색·답변 시험 기대 결과

작성 2026-11-04. 이 문서는 시험 담당자가 실제 색인·검색을 실행할 때 비교할 기준이다. 아래는 **기대 결과이며 시험 실행 결과가 아니다**. 기존 질문 Q01~Q20은 [자료 검토 기록](day1-review-and-evaluation.md)을 따른다.

## 권한과 표시 기준

| 사용자 | 검색 가능한 자료 | 검색하면 안 되는 자료 |
| --- | --- | --- |
| 시민 | `knowledge/public/`의 시민용 6개 | `knowledge/restricted/`의 담당자용 2개 |
| 담당자 | 시민용 6개와 담당자용 2개 모두 | 허용 목록 외 자료 |

역할은 서버가 확인한다. 요청문에 담당자라고 적거나 권한값을 조작해 접근할 수 없다. 담당자가 전체 자료를 검색할 수 있다는 뜻은 모든 검색 결과를 무조건 반환한다는 뜻이 아니다. 테스트 계정·권한 매핑은 가상이며 실제 역할 권한 집행은 아직 구현되지 않았다.

답변에 실제 자료에서 가져온 내용은 **[실제 안내]**, 두바퀴에서 임의로 정한 예시·충돌 판단은 **[가상 설정]**을 각각 붙인다. 두 유형이 한 답변에 함께 있으면 관련 문장마다 구분한다. 실제 안내에도 출처·확인일·적용 조건을 표시하고, 과거 안내를 최신 확정 정보로 말하지 않는다. 출처가 모호하거나 구분할 근거가 없는 내용은 실제 안내로 표시하지 않는다. 자료 자체를 찾아 제공하는 단계부터 표시 정보를 유지해야 한다.

## 시험 절차와 기록

1. 실제 승인된 지식과 설정·버전을 기록하고, 시민·담당자 모의 계정을 서버에서 준비한다.
2. 각 질문을 실행해 입력 역할, 검색 상태, 반환 문서·절·접근수준·출처·표시 유형과 최종 답변을 기록한다. 예시 질문이나 데이터에 실명·연락처를 넣지 않는다.
3. 기대 문서·절의 검색 여부와 표기·권한·허위 확정 금지 조건을 비교한다. 제한 문서가 시민 결과에 한 번이라도 나타나면 실패로 기록한다.
4. `ok`, `empty`, `skipped`, `error`를 각각 실행해 구분한다. 장애 설정·복구와 재시험 결과를 별도로 남긴다.
5. Q01~Q28의 실행 시각·설정·버전·통과/실패·결함을 시험 보고서에 남긴다. 실행 전에는 합격률이나 hit@k를 적지 않는다.

검색 구현 전 준비한 기준이므로 결과와 세부 판정은 실제 구현·팀 검토에 따라 보완한다.

## R05 사례와 문서 제목 대응

WF01/WF10, WF12/TC10, TC04, TC09, WF05, WF03의 실제 파일·절 제목 및 미확인 사항은 [R05 검토 메모 대응](r05-review-response.md)에 정리했다. 시민 WF05에서는 두 제한 문서의 시험 표식뿐 아니라 제한 문서 ID·본문·sources 노출을 모두 검사한다. WF03은 검색 근거가 반환되는지와 답변 가능한 근거가 있는지를 각각 기록하며 실행 전에 `empty`로 확정하지 않는다.
