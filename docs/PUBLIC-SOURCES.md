# 공개 저장소의 출처와 로컬 보존 자료

강의/가이드 원문·조사/학습 원본·팀원 자료·앱 화면·서버 기록·과거 검토 사본은 로컬에
보존하고 Git 추적에서는 제외한다. 공개 문서에서 해당 자료로 향하던 링크는 이 안내로
연결한다. 로컬 경로와 자료의 의미는 문서의 SRC/E·사례 ID·절 설명으로 구분한다.

- [과정 제공 저장소](https://gl.isitsoft.kr/publicproj/aio-01d4-stu/): 과제·강의의 원래 제공처.
- [서울 열린데이터광장](https://data.seoul.go.kr/): 조사 데이터의 원래 제공처.
- [따릉이 공식 사이트](https://www.bikeseoul.com/): 시민 이용 안내의 확인 출발점.

이 링크로 모든 인용의 현재성·이용 조건을 확정하지 않는다. 실제 서비스 지식에는 항목별
출처·확인일·적용 범위·이용 조건을 검토해 반영한다. 모의 정책은 기관의 확정 SOP가 아니다.
제외 자료가 필요한 조사 재현은 공개 저장소만으로 보장하지 않는다.

로컬 보존 파일은 원래 경로와 `docs/LOCAL-INDEX.md`에서 찾아볼 수 있다. 이 로컬 안내도
공개 추적 대상은 아니다. 새 자료가 필요하면 자료 소유자에게 출처와 확인 범위를 문의한다.
