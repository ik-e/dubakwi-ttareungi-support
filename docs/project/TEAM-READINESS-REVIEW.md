## 3 공유와 실제 착수의 구분

지금 공유 가능한 것은 설계/계약 초안·우선순위·역할 ID·작업/품질 기준이다. 모의 응답으로 병행 개발하고 R05는 기대값을 작성할 수 있다. 실제 Jira/DB/Discord를 연결하기 전에는 [첫 회의 확인표](../TEAM-START.md#1-첫-회의에서-역할과-환경-확인)의 역할 배정·접두사·VM·D01/D03/D07·주제 확인을 해소한다.

모든 내부 선택을 공통 결정으로 묶지는 않는다. R03 청킹/검색 비교, R02 프롬프트, R04 저장 드라이버처럼 공개 계약을 유지하는 내부 구현은 해당 담당자가 결정/측정한다. 필드·상태 의미·권한·SLA가 바뀌면 생산/소비 역할과 R05가 함께 검토한다.

기능 동결·발표자1명·19분+여유1분/질의5분·공통 판정은 유지한다. R04 작업 집중이 실제 일정 위험이므로 R01 환경·R05 시험 지원과 Jira/저장→Discord 순서를 계획대로 지킨다. 구현 전인 현재 문서만으로 3일 내 완성이나 검색 최적성을 보장하지 않는다.
