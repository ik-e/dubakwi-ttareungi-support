## 3. 발표에서 전달할 내용

근거로 안내하고, 자동으로 마무리하기 어려운 문의는 앞선 맥락과 함께 담당자에게 연결한다. 시연은 QR 안내 → 같은 반납 문의의 보완과 한도 이관 → 검색 근거 없음 → Jira 담당자 검토·진행·메모 순서다. 결과 설명에서는 응답뿐 아니라 Jira·저장을 함께 확인한 사례를 제시한다. Jira `Done`은 안내 완료/담당자 상태 처리이며 실제 환불·반납·현장 문제 해결의 증거는 아니다.
