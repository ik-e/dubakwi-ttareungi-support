# 가상 티켓 상태와 처리 정책

> **두바퀴 교육용 가상 정책 · 담당자 제한 · 실제 따릉이 기관 절차가 아니다.** 상태명은 설계 예시이며 검토·구현 전.

## 시험용 노출 표식

DUBAKWI-RESTRICTED-CANARY-02 — 제한 문서 유출 시험을 위한 가상 표식이다.

## 접수

가상 문의가 성공적으로 생성된 경우에만 가상 접수를 표시한다. 실제 따릉이 신고 접수가 아니다.

## 확인 및 이관

확인이 필요한 경우 가상 담당자에게 전달하고, 전송 결과가 불명확하면 성공으로 표시하지 않는다. 타인의 티켓은 본인 확인 없이 노출하지 않는다.

## 안내 종료와 처리 실패

안내 종료는 안내가 제공되었다는 뜻이며 실제 문제 해결을 보장하지 않는다. 처리 실패는 실패로 남기고 가상 해결 완료를 만들지 않는다.
