# 상담·후속 문의 안내

> 검토용 지식 초안 · 2026-11-04. 시민용. 실제 따릉이 안내와 **두바퀴 교육용 가상 설정**을 구분한다. 팀 검토·승인 및 실제 색인 전이다. 가상 설정은 실제 따릉이 정책이 아니다.

## 상담원 연결

서울시 2025년 안내에는 앱 채팅상담의 상담사 연결이 평일 09:00~18:00, 점심시간 제외로 소개되어 있다. 점심시간 세부 시간과 현재 운영 여부는 미확인이다. 따릉이 고객센터 번호는 제공된 챗봇에 1599-0120으로 기재되어 있다.

출처: [서울시 챗봇 안내](https://scpm.seoul.go.kr/seoul-policy/evt0223), 사용자 제공 챗봇. 확인 2026-11-04.

## 분실물·습득물

제공된 챗봇은 분실물 문의 전 반납한 대여소와 자전거 번호를 확인하도록 안내한다. 구체적인 신고 버튼과 습득물 보관·반환 절차는 확인하지 못했다. 자전거 자체의 도난과 물건 분실을 구분한다.

출처: 사용자 제공 따릉이 앱 챗봇. 전달 2026-11-04.

## 분실물 접수 — 교육용 가상 설정

**가상 설정:** 두바퀴 시연은 분실물 종류, 마지막 이용 대여소·대략적인 시각과 자전거 번호를 확인해 가상 문의로 전달한다. 실제 접수, 회수, 보관 위치를 의미하지 않는다.

출처: 두바퀴 가상 시연 설계. 실제 따릉이 정책이 아니다.

## 상담 시간·처리 상태 — 교육용 가상 설정

**가상 설정:** 시연에서는 평일 09:00~18:00에 가상 상담원을 이용할 수 있다고 가정하며 점심시간은 별도로 판단하지 않는다. 실제 운영시간이 아니다. 가상 문의 상태는 모의 기록으로만 조회하며 실제 따릉이 처리 상태를 알 수 없다.

출처: 2025년 서울시 안내를 참고한 두바퀴 가상 시연. 실제 현행 상담시간과 조회 절차는 미확인.
