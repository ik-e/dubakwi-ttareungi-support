# 다섯 시민 계정 준비 완료

2026-11-06 KST, R01. 사용자가 제공한 다섯 Discord 계정을 각각 citizen-a~e에 연결했다. 기존 두 매핑은 유지했고 새 세 계정은 c/d/e로 분리했다. 사용자 API에 없던 d/e는 시민/public으로 추가했으며 실제 연락처는 수집하지 않았다. 소스 모의 users.json을 운영 자료로 덮어쓰지 않고 기존 런타임 자료를 보존한 비공개 파일과 읽기전용 Compose override로 연결했다. 재배포 시 이 override를 함께 사용하도록 VM 비공개 인계에 기록했다.

사용자 API 내부 별칭 경유 인증 GET5건 모두200·정확한id/citizen/public을 확인했다. 봇 런타임의 서로 다른5개 매핑, running/restart0/Gateway 연결을 확인했다. 기존 이미지와 비밀파일을 유지하고 사용자API/봇만 재기동했다. n8n 재시작·Jira쓰기·DB변경은 없었다. 설정 전 파일을 비공개로 백업했다.

이 검증은 계정 등록/권한 공급/봇 접속 확인이다. 새 계정 각각의 실제 Discord 문의, 본인/타인 접근의 공식 판정은 별도다. 실제 Discord ID·허용목록·사용자 파일은 공개하지 않는다.
