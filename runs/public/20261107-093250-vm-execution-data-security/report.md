입력 거절 HTTP400은 인증을 통과해 본체 입력 오류 봉투를 반환한 경계만 확인한다. 실패 엔진/수동 실행의 실제 고장 주입은 하지 않았으며 해당 저장 플래그는 설정 검사다. 재배포 도구는 로컬에서 설정 적용·업무/원본 보존·반복 적용 동일·무관 workflow 거절을 확인했다.

## 정정과 후속

초기 저장 설정 미반영 추정은 deletedAt를 보지 않은 판단이었다. 이후 삭제 대기임을 확인해 정정했다. 그 과정에서 B17을 게시 해제/재게시1회 했으나 업무 노드·Credential·연결은 그대로다. n8n 재시작0이다.

이 결과를 ‘평문 키가 DB에 전혀 저장되지 않음’으로 체크하지 않는다. 현재 팀 키 교체, 엔진 저장 이전의 인증 데이터 최소화, 원문 정리와 공식 시험 증거 보존의 조율이 남았다. 외부 유출 여부·PDF 전체·키의 부정 사용 여부는 미검사다.
