# PR36 로컬 통합 검증

2026-11-07 / R01 대리 편집 / P09·P12·P18·P19·P20·P22·P28. PR36 작업 트리의 미커밋 후보다. 기준과 핵심 원본 해시는 [summary.json](summary.json)에 있다. 원격 PR·VM·실제 Jira는 변경하지 않았다.

## 수정한 경계

- 공유 JS/Python 문맥 파서로 Jira key·scope·소유자·문의·첫 요청·작성자·revision을 검증한다. 불완전 페이지와 불일치는 안전 차단한다.
- 기존001~007을 보존하고008/009를 추가했다. latest_completed 문맥과 readonly records 권한을 분리하고 실제 실행 로그인에 DB 시간 제한을 둔다.
- handoff/state의 문맥 저장·재조회·최종 save 게이트, 남은 시간 검사와 반복 쓰기 방지를 연결했다. 공개 version은 null이며 revision은 내부 값이다.
- 사용자 API에 실제 DB/Jira 읽기 provider를 넣었다. 오류 때 모의 records로 대체하지 않으며 시민 소유권·검증된 Jira 문맥을 확인한다.
- support 후속/조회 계약과 TC12·출처 문구 수정, 제한적 답변 검증을 통합했다. errors에는 기존 운영 알림 API의 수락/실패/미확인을 구분했다.
- 인증 뒤 업무 실행 데이터 생성 전에 팀 인증 헤더를 제거하는 고정 n8n 이미지 후보와 경계 고장 사본 도구를 만들었다.
- R05 원본 실패·반복 결과와 미구현 복구를 보존했다. 충돌 이력과 PR24 발표 자료는 비공개로 분리했고 공개 정책을 완화하지 않았다.
