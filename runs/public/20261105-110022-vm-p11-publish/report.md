# P11 VM 게시·입력 부분 시험

- 실행일: 2026-11-05 KST. R01 P04/P13. 기준 main `0e44fdb`, n8n2.42.6.
- 기존 OpenAI Credential을 포함한 변경 전 SQLite 온라인 백업의 무결성·체크섬을 확인했다. 전체 복원 시험은 하지 않았다.
- 기존 팀/내부 키 후보를 Header Auth로 등록하고 P11 B01에 환경 Credential ID를 연결·게시했다. 업무 노드·연결·설정은 수정하지 않았다. 재시작 없이 운영 경로가 활성화됐다.

총10건 중10건 통과다. 인증 거절은 실행을 만들지 않았고 유효 키 입력6건은 실행 ID1~6으로 저장됐다. 저장된 실행은 B01→B02→B03→B33→B35→B36이며 B04·M01은0회다. 실행 목록과 개별 실행 화면 접근을 확인했다. P11에는 LLM/티켓 노드가 없으므로 완성본 연결 후 같은 차단/거절 사례를 다시 시험해야 한다.

B35 메타 기록은6건 모두 ECONNABORTED 출력이었다. 응답 유지 동작과 실행 저장은 확인했지만 data-api 메타 로그 기록 성공으로 표시하지 않는다. R04 data-api 공급/네트워크 연결이 후속이다.
