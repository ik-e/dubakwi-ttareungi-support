첫 공개 검사에서는 지식 디렉터리 링크와 제외한 화면 버튼 연결을 발견해 manifest·공개 기록으로 교체했다. 검사기의 정적 앵커 판정은 실제 `#slide-N` 라우팅을, R02 시나리오 검사는 S/F 식별자 구조를 반영해 수정했다. 최초 실패·후속 성공 JSON을 모두 보존한다. 그림을 삭제한 뒤 빈 버튼을 남기지 않고, Discord/Jira 기록과 PDF 공개 텍스트를 여는 동작을 DOM에서 확인했다.

`git diff --cached --check`의 공개 파생 SVG/HTML 공백 경고 5곳은 공개 사본에서 정리했다. 원본은 변경하지 않았다. 새 CI 단계가 fresh checkout에서 `check_public_submission.cjs`를 실행하므로 공개 사본이 로컬 원본에 의존하면 실패한다.

추가 가림 검사에서 자료 읽기용 데이터의 비표시 `text`/`heading` 원문 필드에 개인 표기가 남은 것을 발견했다. 공개에 쓰는 검토한 HTML만 남기고 사용하지 않는 원문 필드는 제거했으며, 생성 도구와 CI에 재발 방지 검사를 추가했다. [최초 발견](publication-review.json)과 [가림 후 판정](publication-review-final.json)을 보존했다. 해당 사본은 외부 push 전에 수정했다. `git-candidates-final.json`의 자기 보고서 링크 1건은 파일이 생성되기 전 확인된 것으로, 이후 검사에서는 실제 파일을 포함해 오류0이다.

기존 GitHub 연결 도구의 계정은 이 저장소 쓰기 권한이 없어 앞선 PR54 때와 같은 저장소 소유자의 로컬 Git/CLI 계정을 사용한다. 현재 저장소 공개 상태와 기본 브랜치 main, 해당 계정의 ADMIN 권한을 읽기 전용으로 확인했다. 새 계정이나 권한을 추가하지 않았다. 최종 커밋·PR·CI·main 반영은 Git 이력과 후속 확인 기록을 따른다.
