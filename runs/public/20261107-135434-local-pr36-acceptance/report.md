## 통과로 처리하지 않은 항목

- 실제 RAG HTTP7건은 실행 환경/내부 인증과 외부 임베딩 비용이 필요한 시험이라 생략했다. 모의 시험으로 대신 통과 처리하지 않았다.

- 실제 LLM 의미 검증/과도 이관·검색 지연 원인·실제 권한/시간/고장/부작용·키 교체·전체 복원·최종 제출/역할 회신·동결은 후속이다.
- 일부 과정 원본과 R05 화면17장은 현재 로컬에 없으므로 원문/장별 가림을 확인하지 않았다.
