## 효과와 제한

이번 구간에서 Discord 문의 5회와 ephemeral 응답을 관측했다. D02/D03 응답에서 Jira 키가 반환되지 않아 이 실행의 Jira 생성·조회 효과는 UI로 확인되지 않았다. DB의 요청/state 기록은 직접 조회하지 않았으므로 쓰기 0건으로 단정하지 않는다. Jira 상태 변경, Discord 공개 알림, n8n workflow 변경/호출은 수행하지 않았다.

D03은 같은 문의 연결 유지까지만 확인했고 Jira 재사용은 미확인이다. D05/D06(미등록·타 이용자 경계), D10(같은 interaction 중복 재전달)은 이 UI 입력으로 검증하지 않았다. 기존 같은 날 UAT와 [11/7 VM 통합 실행](../20261107-170503-vm-pr36-integration/report.md)은 별도 증거이며 본 실행에 합산하지 않는다. 전체 UAT는 부분 완료다.
