# 최종 사례·요구 근거 추적표

2026-11-09 · R01 취합. **60개 사례와 64개 요구 ID의 연결 누락은 0**이다. 이는 실행 통과율이 아니다. 기존 원 보고서의 시점·조건을 유지하며 신규 서비스 시험은 0건이다.

## 판정 읽는 법

- PASS_SEARCH_SCOPE: PR36 검색 단위 시험에서 기대 결과 확인.
- PARTIAL_HISTORICAL_RESPONSE: 11/07 통합 보고서의 응답 기대 충족 집합에 속함. 수동 의미 검토·현행 전체 환경 동일성·반복 안정성까지 완료된 PASS가 아님.
- FAIL_ORIGINAL_TIME_ASSERTION: 원 시간 기대 미충족 보존.
- BLOCKED_CURRENT_SPEC: 현행 명세의 격리 종단 미실행.
- NOT_IMPLEMENTED_RECOVERY_ACTION: 조회와 별개인 원 요청 복구 action 미구현/이번 범위 밖.
- NOT_RUN_FINAL_SCOPE: 과거 골격 전용 명세를 현행 업무 결과에 합산하지 않음.
- 요구의 PARTIAL_EVIDENCE는 원 완료 조건 중 실제 확인한 범위만 의미한다. 미완료 요구를 일괄 완료 처리하지 않는다.

## 공통 14유형과 세부 수
