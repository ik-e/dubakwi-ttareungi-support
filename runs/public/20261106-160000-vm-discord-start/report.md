2026-11-06 KST, R01. #40 병합본 첫 기동에서 읽기전용 파일시스템의 uv 캐시 오류를 확인했다. #41에서 빌드된 Python을 직접 실행하도록 수정했고 어댑터22/22·CI통과 후 main37ec341로 다시 빌드했다. 이미지ID는 summary에 고정했다. 봇만 기동했으며 n8n 재시작은 없었다.

실제 컨테이너 running/restart0/read_only/UID65532, Gateway 연결 로그를 확인했다. 토큰·키·허용 서버/채널·사용자 매핑은 저장소 밖 비공개 파일을 사용한다. 실제 문의 사용자가 미등록 안내를 받았고 실행 로그의 거절과 설정된2개 매핑의 입력값 일치를 확인했다. 미등록 분기는 본체 호출 전에 반환한다. 등록 사용자 Discord 정상 종단은 아직 통과가 아니며 실제 실행 계정 ID 확인 후 재시험한다.

원복은 discord-bot 서비스만 중지한다. 기존 Jira·DB·DLQ는 정리하지 않는다. 역할별 최종 확인은 사용자 지시대로 후속이며 실제 승인 수령으로 대체하지 않는다.
