# 실행 도구

조사 재현과 문서·출처 검사를 위한 기존 도구를 유지합니다. 개발/배포 도구는 `scripts/dev/`(R01), 시험/측정 도구는 `scripts/test/`(R05)에 필요한 때 추가합니다. 검색 평가 로직은 R03이 제공하며 경로별 소유권은 [헌장](../docs/project/TEAM-CHARTER.md), 절차는 [AGENTS](../AGENTS.md)를 따릅니다.

- [조사·문서 관리 스크립트 — 공개본 제외 자료](../docs/PUBLIC-SOURCES.md)
- [공개본 생성 도구](dev/README.md): 허용 파일만 복사하고 원문 링크를 공개 출처 안내로 전환합니다.
- [팀 문서 검사 도구](test/README.md): 현행 팀 문서의 로컬 링크·앵커·표를 읽기 전용으로 검사합니다. 서비스 실행 시험과 구분합니다.
- [서버 자원 확인 스크립트 — 공개본 제외 자료](../docs/PUBLIC-SOURCES.md): 실행 대상의 현재 자원을 읽습니다. 과거 측정 결과는 [문서 — 공개본 제외 자료](../docs/PUBLIC-SOURCES.md)에 있습니다.
- [프로젝트 대문](../README.md)
